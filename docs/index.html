XDDBOT

Открытый клиент-компаньон для вашего собственного электросамоката: подключение по BLE, диагностика, команды и работа с вашим ключом устройства.

Материи Design You, без телеметрии в чужие сервисы и без чужой рекламы.

Скачать APK Как установить

Только ваши устройства. XDDBOT хранит и передаёт лишь те ключи, которые вы вводите сами. В приложении нет генерации ключей, подбора, перебора или обхода чужих замков. Используйте его только на самокатах, которыми владеете вы или на работу с которыми у вас есть разрешение.

Что это

Компаньон, не замена

XDDBOT не включает самокат «магически». Он повторяет штатный обмен того же типа, что и официальное приложение, используя ваш ключ.

BLE

Свой ключ

Ключ устройства вы берёте там, где он у вас есть, и вводите вручную. Хранится в зашифрованном виде на телефоне.

Установка

Четыре шага: поставить APK, ввести свой ключ, выдать разрешения, подключиться.

Установите APK

Скачайте app-release.apk со страницы Releases и откройте файл. Подтвердите установку из неизвестного источника.

Debug-сборки имеют суффикс .debug и ставятся рядом с release-версией.

Добавьте свой ключ

Откройте вкладку Настройки → Добавить ключ. Укажите название, hex-ключ и deviceType (по умолчанию 66). Новый ключ сразу становится активным.

Ключ хранится только на телефоне в зашифрованном виде и передаётся лишь подключённому самокату при рукопожатии.

Выдайте разрешения

При первом скане приложение попросит доступ к Bluetooth. На Android 11 и ниже дополнительно нужен доступ к геолокации — так устроена система для BLE-сканирования.

Подключитесь

Во вкладке Скан выберите свой самокат. После подключения откроется экран Устройство с активным ключом и статусом.

Без железа включите демо-режим, чтобы пройти интерфейс.

Проверка контрольной суммы APK: после скачивания можно сверить SHA-256 с тем, что указан в описании релиза.

Ключи

Как XDDBOT работает с ключом устройства — и почему только с вашим.

Что такое ключ устройства

Это набор байт, который используется при рукопожатии: телефон и самокат подтверждают друг другу «свой» и только затем принимают команды. Ключ принадлежит конкретному самокату.

XDDBOT не создаёт и не подбирает ключи. Он принимает только то значение, которое вы ввели вручную. Если у вас нет ключа — приложение не поможет его «найти».

Правила ввода

Только hex

Символы 0-9, A-F. Пробелы игнорируются, префикс 0x отбрасывается.

Формат

Чётная длина

Число hex-символов должно делиться на два — каждая пара это один байт.

Проверка

Не длиннее 64 байт

Верхний предел, чтобы отсекать случайную вставку. Для самоката обычно достаточно нескольких байт.

Лимит

deviceType 0..255

Целое число. Значение по умолчанию — 66 (XM-профиль).

Профиль

Хранение

Ключи лежат в файле настроек, зашифрованном мастер-ключом из Android Keystore (EncryptedSharedPreferences, AES-256). Резервное копирование приложения отключено, поэтому ключи не уезжают в бэкап облака.

API-модель профиля

BleKey(
  id         = "<uuid>",      // идентификатор профиля
  label      = "Мой самокат", // произвольное имя
  keyHex     = "a1b2c3d4",    // normalised, без пробелов
  deviceType = 66             // 0..255
)

Протокол BLE

Формат кадра, контрольные суммы, рукопожатие и команды. Реализация — модуль xdbot.bitplugg.ru.protocol.

Кадр

Каждый кадр маскируется случайным байтом rand, чтобы не стоял постоянный паттерн.

A3 A4 len (rand+50) (devType^rand) (cmd^rand) payload^rand crc8

A3 A4 — маркер

Начало кадра.

len

Длина payload в байтах.

rand

Случайный байт; в кадре хранится как rand + 50.

маскирование

devType, cmd и payload побитово XOR-ятся с rand.

crc8

Контрольная сумма CRC-8/MAXIM по кадру.

Контрольные суммы

CRC-8/MAXIM (Dallas)

Для отдельного кадра. Полином отражённый, табличный. Проверочное значение для "123456789" — 0xA1.

Кадр

CRC-16/MODBUS

Для блока передачи данных. Отражённый полином 0xA001, init 0xFFFF. Проверочное значение — 0x4B37.

Передача

Рукопожатие и передача данных

  1. COMMUNICATION_KEYОпкод 1. Телефон и устройство обмениваются ключом и открывают сессию.
  2. STARTОпкод 0xFB (251). Объявляет тип передачи, число пакетов, CRC-16 и deviceType.
  3. DATAОпкод 0xFC (252). Данные нарезаны по 16 байт, каждый пакет со своим CRC-16.

FAQ

Частые вопросы по установке и работе.

Приложение не находит мой самокат

Убедитесь, что самокат включён, находится рядом и что выданы разрешения на Bluetooth (на Android 11 и ниже — и на геолокацию). Иногда помогает выключить и снова включить Bluetooth.

Где взять ключ устройства?

Ключ принадлежит вашему самокату. XDDBOT его не добывает и не подбирает. Вводите только то значение, которым вы законно располагаете.

Можно ли пользоваться без самоката?

Да, включите демо-режим. Интерфейс, журнал и настройки работают без железа; реального обмена по BLE не будет.

Теряется ли ключ при обновлении?

Нет. Ключи хранятся в зашифрованных настройках приложения. Debug-сборка (.debug) — отдельное приложение со своими настройками.

Отправляет ли приложение что-то на серверы?

Статический API на GitHub Pages читается для проверки версии и профилей устройств — без пользовательских данных. Опциональная анонимная телеметрия по умолчанию выключена и включается только вручную в настройках. Подробнее — в разделе «Приватность».

Работает ли на iOS?

Нет, проект только под Android (Kotlin + Jetpack Compose).

Приватность

Что XDDBOT делает и не делает с вашими данными.

Коротко

Ключи — только на телефоне

Введённые вами ключи хранятся локально в зашифрованном виде (EncryptedSharedPreferences) и передаются только подключённому самокату при рукопожатии.

Локально

Телеметрия выключена по умолчанию

Приложение не отправляет данные, пока вы сами не включите анонимную телеметрию в настройках.

Opt-in

Без рекламы и сторонних SDK

Нет рекламных сетей, трекеров и аналитических библиотек третьих сторон.

Нет

Если вы включите телеметрию

Отправляются только:

  • имя события — например, «запуск», «подключение», «команда»;
  • версия приложения;
  • случайный идентификатор установки (не связан с вами).

Никогда не отправляются: ключи и коды, адреса и имена BLE-устройств, координаты, содержимое журнала обмена. Сборщик отбрасывает запросы с такими данными.

Телеметрию можно выключить в любой момент в разделе «Настройки» — это прекращает отправку.

Что приложение читает из сети

Статический API на GitHub Pages: version.json для проверки обновлений и devices.json со списком профилей устройств. Это обычные публичные файлы без авторизации и без пользовательских данных.
